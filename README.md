# Toolshop QA

Учебный проект по ручному тестированию демо-магазина Toolshop
(версия «с багами» проекта Practice Software Testing).
Здесь я складываю свои тест-артефакты: тест-план, тест-кейсы, чек-листы и баг-репорты.

## Тестируемое приложение
- Сайт: https://with-bugs.practicesoftwaretesting.com
- API: https://api-with-bugs.practicesoftwaretesting.com
- Стек: Angular + Laravel (PHP), MySQL

## Зачем
Отрабатываю полный цикл ручного тестирования на реальном веб-приложении
и собираю материалы для QA-портфолио.

## Структура репозитория
- `test-plan/` — тест-план
- `test-cases/` — тест-кейсы и чек-листы
- `bug-reports/` — баг-репорты
- `assets/` — скриншоты
