# Чек-лист: Toolshop
## Общие элементы (шапка/навигация)
- [ ] Все пункты меню присутствуют и корректно подписаны
- [ ] Каждый пункт меню ведёт на нужную страницу
- [ ] Счётчик товаров в корзине отображает верное количество
- [ ] Логотип виден и ведёт на главную

## Каталог товаров
- [ ] Открывается главная страница со списком товаров
- [ ] Отображаются изображения, цены, название
- [ ] Карточка товара открывается по клику
- [ ] В карточке отображается, цена, описание, бренд

## Поиск и фильтры
- [ ] Поиск находит товар по названию
- [ ] Поиск по несуществующему товару показывает корректное сообщение
- [ ] Работает фильтр по категории
- [ ] Работает фильтр по бренду
- [ ] Работает фильтр по цене

## Корзина
- [ ] Корзина открывается
- [ ] Отображаются добавленные товары (название, цена, количество)
- [ ] Можно увеличить количество товара
- [ ] Можно уменьшить количество товара
- [ ] При изменении количества пересчитывается стоимость
- [ ] Корректно считается итоговая сумма по всем товарам
- [ ] Товар удаляется из корзины
- [ ] Отображается корректное состояние пустой корзины
- [ ] Есть переход к оформлению заказа
      
## Оформление
- [ ] Из корзины выполняется переход на страницу оформления заказа
## Оформление заказа - Адрес
- [ ] Открывается шаг ввода адреса
- [ ] Поля адреса принимают корректные данные
- [ ] Обязательные поля нельзя оставить пустыми
- [ ] Поля отклоняют некорректный формат
- [ ] Введенные данные сохраняются при переходе к следующему шагу
- [ ] Кнопка перехода активна только при заполненных данных
## Оформление заказа - Оплата
- [ ] Открывается шаг оплаты
- [ ] Присутствует список способов оплаты
- [ ] Список способов оплаты содержит только валидные варианты
- [ ] По умолчанию выбран корректный способ (или предложено выбрать)
- [ ] Можно выбрать способ оплаты из списка
- [ ] Поля оплаты отклоняют некорректные данные
- [ ] Сообщение об успешной оплате появляется только после подтверждения (Confirm)
- [ ] После подтверждения отображается результат заказа
      
## Регистрация и вход
- [ ] Открывается форма входа
- [ ] Вход с верными данными проходит успешно
- [ ] Вход с неверными данными отклоняется с сообщением об ошибке
- [ ] Работает выход из аккаунта
- [ ] Открывается форма регистрации
- [ ] Обязательные поля нельзя пропустить
- [ ] Регистрация с валидными данными проходит успешно
- [ ] Регистрация с уже существующим email отклоняется
- [ ] Открывается форма входа
      
## Страница товара
- [ ] Отображаются название, цена, описание, изображение, бренд
- [ ] Работает выбор количества
- [ ] Количество не принимает 0 и отрицательные значения
- [ ] Кнопка "Добавить в корзину" работает
- [ ] После добавления обновляется счётчик корзины
- [ ] Работает добавление в избранное (Favorites)
- [ ] Товар "нет в наличии" нельзя добавить в корзину

## Личный кабинет
- [ ] Открывается страница профиля
- [ ] Отображаются данные пользователя
- [ ] Данные профиля можно отредактировать и сохранить
- [ ] Открывается список избранного (Favorites)
- [ ] Товар удаляется из избранного
- [ ] Открывается история заказов / счета (Invoices)


## Контакты
- [ ] Открывается форма обратной связи
- [ ] Обязательные поля нельзя оставить пустыми
- [ ] Поле сообщения имеет ограничение по длине
- [ ] Можно прикрепить файл (если предусмотрено)
- [ ] Отправка с валидными данными проходит успешно
- [ ] Отображается подтверждение отправки
