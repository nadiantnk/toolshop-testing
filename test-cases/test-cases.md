# Тест-кейсы: Toolshop
## TC-01. Успешный вход с валидными данными

| Поле | Значение |
|------|----------|
| **ID** | TC-01 |
| **Приоритет** | Высокий |
| **Предусловие** | Пользователь зарегистрирован (customer@practicesoftwaretesting.com / welcome01), не залогинен |

**Шаги:**
1. Открыть страницу входа (Sign in).
2. В поле Email ввести `customer@practicesoftwaretesting.com`.
3. В поле Password ввести `welcome01`.
4. Нажать кнопку Login.

**Ожидаемый результат:**
- Вход выполнен успешно.
- Происходит переход в личный кабинет (My account).
- В шапке отображается имя пользователя.

## TC-02. Добавление товара в корзину.

| Поле | Значение |
|------|----------|
|**ID**| TC-02    |
|**Приоритет**| Высокий|
|**Предусловие**|Открыт каталог товаров, корзина пуста|

**Шаги:**
1. Открыть страницу любого товара в наличии.
2. Убедиться, что счетчик корзины показывает 0.
3. Нажать кнопку "Add to cart".
4. Открыть корзину

**Ожидаемый результат** 
- После добавления счётчик корзины увеличивается на 1.
- Появляется уведомление о добавлении товара.
- В корзине отображается добавленный товар: название, цена, количество = 1.
- Название и цена в корзине совпадают со страницей товара.

## TC-03. Изменение количества и пересчёт суммы

| Поле | Значение |
|------|----------|
| **ID** | TC-03 |
| **Приоритет** | Высокий |
| **Предусловие** | В корзину добавлен один товар, корзина открыта |

**Шаги:**
1. Зафиксировать количество товара и цену.
2. Увеличить количество товаров до 2.
3. Проверить сумму товара.
4. Проверить сумму в корзине.

**Ожидаемый результат**
- Количество меняется на 2.
- Сумма по строке товара = цена × 2.
- Итоговая сумма корзины пересчитывается и равна сумме по строке.
- Значения отображаются в корректном формате.

## TC-06. Успешная регистрация нового пользователя

| Поле | Значение |
|------|----------|
| **ID** | TC-06 |
| **Приоритет** | Высокий |
| **Предусловие** | Пользователь не зарегистрирован, открыта страница входа |

**Шаги:**
1. Заполнить First name и Last name.
2. Указать Date of birth в формате YYYY-MM-DD.
3. Заполнить Address, Postcode, City.
4. Заполнить Country, выбрать State из выпадающего списка.
5. Заполнить Phone.
6. Ввести валидный Email, не занятый в системе.
7. Ввести пароль, удовлетворяющий требованиям формы.
8. Нажать кнопку Register.

**Ожидаемый результат:**
- Все обязательные поля приняты, ошибок валидации нет.
- Регистрация проходит успешно, происходит переход на страницу входа (Login).
- Под введёнными Email и паролем удаётся войти в личный кабинет (My account).

## TC-07. Сортировка по цене (Low → High)

| Поле | Значение |
|------|----------|
| **ID** | TC-07 |
| **Приоритет** | Высокий |
| **Предусловие** | Открыта страница каталога, фильтры не применены |

**Шаги:**
1. В блоке Sort выбрать вариант "Price (Low - High)".
2. Посмотреть список товаров.
3. Сравнить цену первого товара с ценой последнего.

**Ожидаемый результат:**
- Товары отсортированы по возрастанию цены.
- Первый товар имеет наименьшую цену, последний — наибольшую.
- Порядок сохраняется при прокрутке до конца списка.
