## BUG-001: Названия товаров смещаются по горизонтали при движении ползунка цены
| Поле | Значение |
| --- | --- |
| **Компонент** | Каталог, фильтры |
| **Severity** | Minor |
| **Priority** | Medium |
| **Окружение** | Windows 11, Brave 1.93.132, Firefox 153.0.1 |
| **URL** | https://with-bugs.practicesoftwaretesting.com/#/|
| **Воспроизводимость** | Всегда|

**Предусловия:**
Открыт каталог товаров, Price Range выбран по умолчанию, фильтр не тронут.

**Шаги воспроизведения:**
1. В поле Price Range передвинуть правую границу ползунка влево
2. Наблюдать за названиями товаров, во время движения ползунка

**Фактический результат:**
Названия товаров смещаются по горизонтали.
**Ожидаемый результат:**
Названия товаров останутся на месте, горизонтального смещения при движении ползунка нет.
