## BUG-001: Названия товаров смещаются по горизонтали при движении ползунка цены
| Поле | Значение |
| --- | --- |
| **Компонент** | Каталог, фильтры |
| **Severity** | Minor |
| **Priority** | Medium |
| **Окружение** | Windows 11, Brave 1.93.132, Firefox 153.0.1 |
| **URL** | https://with-bugs.practicesoftwaretesting.com/#/|
| **Воспроизводимость** | Всегда|

**Предусловия:**
Открыт каталог товаров, Price Range выбран по умолчанию, фильтр не тронут.

**Шаги воспроизведения:**
1. В поле Price Range передвинуть правую границу ползунка влево
2. Наблюдать за названиями товаров во время движения ползунка

**Фактический результат:**
Названия товаров смещаются по горизонтали.
**Ожидаемый результат:**
Названия товаров остаются на месте, горизонтального смещения при движении ползунка нет.

## BUG-008: GET /products/{id}/related возвращает 500 для несуществующего товара

| Поле | Значение |
| --- | --- |
| **Компонент** | API, Products |
| **Severity** | Major |
| **Priority** | Medium |
| **Окружение** | API https://api-with-bugs.practicesoftwaretesting.com, Swagger UI |
| **Эндпоинт** | GET /products/{productId}/related |
| **Воспроизводимость** | Всегда |

**Предусловия:**
Доступ к API через Swagger UI.

**Шаги воспроизведения:**
1. Открыть Swagger UI, эндпоинт GET /products/{productId}/related.
2. В поле productId ввести id несуществующего товара (например, 999).
3. Нажать Execute.

**Фактический результат:**
Сервер возвращает 500 Internal Server Error, тело: { "message": "Server Error" }. Код не описан в документации (Undocumented). Воспроизводится для id 0, -4, 999.

**Ожидаемый результат:**
Для несуществующего товара сервер возвращает 404 (ресурс не найден) с понятным сообщением. Ответа 500 быть не должно.
