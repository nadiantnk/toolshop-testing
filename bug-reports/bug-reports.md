## BUG-001: Названия товаров смещаются по горизонтали при движении ползунка цены
| Поле | Значение |
| --- | --- |
| **Компонент** | Каталог, фильтры |
| **Severity** | Minor |
| **Priority** | Medium |
| **Окружение** | Windows 11, Brave 1.93.132, Firefox 153.0.1 |
| **URL** | https://with-bugs.practicesoftwaretesting.com/#/|
| **Воспроизводимость** | Всегда|

**Предусловия:**
Открыт каталог товаров, Price Range выбран по умолчанию, фильтр не тронут.

**Шаги воспроизведения:**
1. В поле Price Range передвинуть правую границу ползунка влево
2. Наблюдать за названиями товаров во время движения ползунка

**Фактический результат:**
Названия товаров смещаются по горизонтали.
**Ожидаемый результат:**
Названия товаров остаются на месте, горизонтального смещения при движении ползунка нет.

## BUG-002: Фильтр по цене (Price Range) не применяется — в выдаче товары вне диапазона

## BUG-003: У авторизованного пользователя не загружаются данные профиля
| Поле | Значение |
| --- | --- |
| **Компонент** | Авторизация, личный кабинет |
| **Severity** | Major |
| **Priority** | High |
| **Окружение** | Windows 11, Brave 1.93.132, Firefox 153.0.1 |
| **URL** | https://with-bugs.practicesoftwaretesting.com/#/account |
| **Воспроизводимость** | Всегда |

**Предусловия:**
Пользователь авторизован под аккаунтом: логин: customer2@practicesoftwaretesting.com  Пароль: welcome01

**Шаги воспроизведения:**
1. Войти в аккаунт с валидными данными.
2. Открыть страницу "Мой аккаунт" (My account).
3. Посмотреть на верхнее меню навигации, открыть DevTools - Console - Network.

**Фактический результат:**
В меню навигации и в блоке аккаунта данные пользователя не отображаются (текст «User Data not found»). В консоли — ошибка: запрос GET /users/me возвращает 401 Unauthorized, данные профиля не загружаются.

**Ожидаемый результат:**
Данные авторизованного пользователя загружаются; в меню отображается имя пользователя, запрос `/users/me` возвращает 200 с данными профиля.

## BUG-004: На карточке товара кнопка "+" не увеличивает количество товара

| --- | --- |
| **Компонент** | Карточка товара |
| **Severity** |  Major |
| **Priority** | High |
| **Окружение** | Windows 11, Brave 1.93.132, Firefox 153.0.1 |
| **URL** | https://with-bugs.practicesoftwaretesting.com/#/product/2 |
| **Воспроизводимость** | Всегда |

**Предусловия:**
Открыта карточка товара, например " Pliers ".

**Шаги воспроизведения:**
1. На карточке товара нажать кнопку "+" рядом с полем количества.
